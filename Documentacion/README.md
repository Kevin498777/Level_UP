# Documentación — Level_UP

Esta carpeta contiene todos los documentos de información del proyecto (no código).
Las reglas de desarrollo se mantienen en la raíz: `../reglas.md`.

| Documento | Contenido |
|---|---|
| `Level_UP_Especificaciones.md` | Especificaciones de juego (no técnico): mundo, terreno, vegetación, personaje, progresión, armas, habilidades, interfaz y controles. Se actualiza cada 3 cambios grandes (ver `reglas.md`, regla 3). |
| `Tablas_Escalado.md` | Tablas de escalado por nivel de cada herramienta y habilidad, generadas a partir de los valores del código. |
| `Tablas_Tipos.xlsx` | Hoja de cálculo de tablas de tipos. |

Cualquier documento nuevo de información del proyecto debe guardarse aquí.
